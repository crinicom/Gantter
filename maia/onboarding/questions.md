# Preguntas para armar la ficha del proyecto (slice 13)

# Las líneas que arrancan con una sola "#" son comentarios (nunca se muestran).
# Cada "## Título" es una pregunta: el título pasa a la Ficha del proyecto y el
# cuerpo es la pregunta que se muestra en el modal. Agregar/quitar reordena el
# onboarding sin tocar código. La Ficha se regenera desde estas respuestas
# mientras el onboarding no esté "done".

Estas preguntas arman la Ficha del proyecto que vive en la pestaña
"Información del proyecto". Se guardan solas con cada respuesta.

## Objetivo
¿Cuál es el objetivo principal del proyecto y qué define que esté bien hecho?

## Entregable
¿Qué hay que entregar primero, y para cuándo?

## Equipo
¿Quién lidera y quiénes participan? ¿Hacen falta más manos?

## Fechas
¿Cuáles son las etapas clave y cuándo es el hito más urgente?

## Riesgos
¿Qué puede retrasar la entrega o romper el plan?
