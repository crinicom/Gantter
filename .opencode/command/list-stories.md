Lista el backlog de historias de usuario de `docs/requirements.md` organizado por estado.

1. Lee `docs/requirements.md`.
2. Presenta las historias agrupadas por estado (pendiente, en-progreso, hecho, cancelada).
3. Para cada historia muestra: ID, título/capacidad y un resumen de su criterio principal.
4. Indica cuántas hay por estado.

Usa $ARGUMENTS para filtrar (p. ej. "pendiente" para ver solo el product backlog).
